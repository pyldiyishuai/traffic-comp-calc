# 交通事故赔偿计算器

> 别只拿医疗费和误工费就签字。
> 十级伤残、40 岁、按全国平均标准，光残疾赔偿金就有 **10.8 万**。

纯静态站点，双击 `index.html` 就能跑。

---

## 一、这个工具解决什么问题

交通事故后，保险公司或肇事方最常用的做法是：
**只算你实际花掉的钱**，然后告诉你「就这么多」。

但法定赔偿有 11 项，其中三项只有构成伤残才产生，却往往是最值钱的：

| 项目 | 十级伤残、40 岁、全国平均 |
|---|---|
| 残疾赔偿金 | **108,376 元** |
| 被扶养人生活费 | 有子女/老人时另计 |
| 精神损害抚慰金 | 5,000 元 |

不算这三项，总额可能只有 10.8 万；算上就变成 **22.2 万**。

**差 11.3 万。** 这就是本工具存在的理由。

## 二、算法依据

### 核心公式

**残疾赔偿金 = 城镇居民人均可支配收入 × 赔偿年限 × 伤残系数**

| 变量 | 规则 |
|---|---|
| 收入基数 | 事故发生地上一年度城镇居民人均可支配收入 |
| 赔偿年限 | 60 岁以下 20 年；60–75 岁每增 1 岁减 1 年；75 岁以上 5 年 |
| 伤残系数 | 1 级 100%，每级递减 10%，10 级 10% |

例：54,188 × 20 × 10% = **108,376 元**

### 交强险优先赔付

很多人的误解是「按责任比例分摊」。实际上：

```
交强险限额内（不按责任比例）：
  医疗费用      18,000
  死亡伤残     180,000
  财产损失       2,000
        ↓
超出部分，才按事故责任比例分摊
```

所以即使对方只有 70% 责任，交强险部分仍全额赔给你。

### 城乡标准已统一

2022 年最高法修改司法解释，**不再区分农村和城镇户口**，
统一按城镇居民人均可支配收入计算。

如果对方还在按「农村标准」算，可以直接指出来。

## 五、改代码前必看

### 1. 数据每年要更新

`data/comp-rules.js` 的 `regions` 是各省**上一年度**统计数据。
每年 1–3 月各省统计公报发布后，整表替换。

**这是这个工具唯一需要定期维护的地方。**

### 2. 伤残系数是「反向」的

1 级最重（100%），10 级最轻（10%）。写 `level * 0.1` 会得到完全错误的结果。

```js
factor = (11 - level) / 10   // ✅ 1 级 = 1.0，10 级 = 0.1
factor = level * 0.1          // ❌ 反了
```

### 3. 交强险三个限额是分开的

医疗费用、死亡伤残、财产损失各有各的限额，不能合并计算。
超出部分按比例分摊时，也要分别算再相加。

### 4. 60 岁是边界不是起点

```js
if (a < 60) return 20;              // 59 岁 → 20 年
if (a < 75) return 20 - Math.floor(a - 60);  // 60 岁 → 20 年（不是 19）
return 5;
```

### 5. hidden input 也要同步 chips

伤残等级用 chips 选择，但值存在 `<input type="hidden" id="level">` 里。
`getValues()` 从 input 读，所以 **chips 点击必须写回 input**，
**恢复 URL/localStorage 时也要反向同步 chips 的高亮**。

## 八、免责

本工具依据《民法典》与最高人民法院《关于审理人身损害赔偿案件适用法律
若干问题的解释》（2022 年修正）计算，收入与支出基数取事故所在地
上一年度统计公报数据。

各地法院掌握尺度存在差异（尤其精神损害抚慰金），
结果仅供参考，不构成法律意见。
